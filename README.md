## 💻 Featured Projects

### 📚 Fiction Book Recommendation System

A recommendation system project using Amazon book ratings and metadata to explore data preprocessing, exploratory analysis, association-rule mining, and Autoencoder-based collaborative filtering.

**Focus areas:** Data cleaning, fuzzy title matching, sparse user–item matrices, Apriori, deep learning, and model evaluation.

🔗 [View Project Repository]([https://github.com/Zafrin-Jolly/ml-project-workflow](https://github.com/Zafrin-Jolly/BHTRecommenderProject))

### 🧬 Snake Venom Protein Classification

A collaborative machine learning project with Luke Richard focused on classifying snake venom proteins into different protein families using traditional machine learning, neural networks, and transformer-based representations.

**Focus areas:**
- Protein sequence classification and preprocessing
- K-mer feature engineering
- Random Forest and MLP model comparison
- Transfer learning with ProtBERT
- Evaluation using accuracy, F1-score, and ROC-AUC

🔗 [View Snake Venom Project](https://github.com/lukedrichard/Snake_Venom_Project)

*Collaborative project developed with Luke Richard.*

### 🌧️ Flood Forecasting in Bangladesh

A time-series forecasting study comparing statistical and forecasting approaches to explore flood prediction using weather-related data.

**Focus areas:** Time-series analysis, ARIMA, SARIMAX, Prophet, and model comparison.

🔗 [View Project Repository](https://github.com/Zafrin-Jolly/Forecasting-Floods-in-Bangladesh-Using-Different-Time-Series-Model-A-Comparative-Analysis)
